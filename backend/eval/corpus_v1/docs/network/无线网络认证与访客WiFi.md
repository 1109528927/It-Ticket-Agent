# 无线网络认证与访客 WiFi

## 区分
- 办公 WiFi：员工账号 / 证书认证，可访问内网（按策略）。
- 访客 WiFi：与办公网隔离，一般不能打打印机、共享盘、内网系统。

## 员工连不上办公 WiFi
1. 是否选对 SSID；忘记网络后重连并更新密码 / 证书。
2. 笔记本无线开关、飞行模式；换手机热点对比是否本机无线故障。
3. 证书过期：按桌面管理推送或 IT 重装无线配置文件。
4. 单人失败多人正常：本机问题；楼层大面积失败：升级网络组。

## 访客与投屏
访客网无法投屏内网设备时，改连会议专用网络，参见「会议室投屏与无线网络」。

## 结案
写清 SSID 类型、认证方式、影响范围。
