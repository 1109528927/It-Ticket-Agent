# 防火墙端口开通申请

## 适用
业务系统互通、第三方对接、开发联调需要在防火墙上放行源 / 目的 IP 与端口。

## 申请必须写清
1. 源地址（网段或主机）、目的地址、协议（TCP/UDP）、端口、方向。
2. 业务负责人、到期日（临时联调必须写到期）。
3. 是否涉及互联网暴露；暴露面变更需安全评估。

## 处理原则
1. 最小权限：能限定源就不要 Any。
2. 变更走网络变更单；本工单台若对接防火墙工单，只做受理与跟踪，不在聊天里「口头放行」。
3. 到期回收与临时权限类似，结案前确认是否设了回收。

## 拒绝常见原因
信息不全、申请公网高危端口无评估、与现有策略冲突。
