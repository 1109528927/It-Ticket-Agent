# 忘记域密码处理手册

## 适用范围
员工登录域账号、办公电脑开机登录、Outlook 等依赖域凭据的场景，报「密码忘了」「提示密码错误」「账号被锁」。

## 受理前核对
1. 工单里的报障人姓名、工号是否与本人一致。
2. 是否本人办理；代提需有工号与联系方式。
3. 近期是否有安全事件（异地登录、钓鱼），有则先升级安全组，不直接重置。

## 标准处理步骤
1. 用工单详情确认描述，不要凭聊天口头假设策略。
2. 在助手或处理页提出「重置密码」，写明目标工号。
3. 等待客服在处理页人工确认后，系统才会真正改密。
4. 确认完成后通知员工：用临时密码登录，并立即修改为个人密码。
5. 禁止在对话中声称「已经重置成功」——未确认前一律未生效。

## 常见话术（草稿，客服可改）
「已为您提交密码重置申请，需客服确认后生效。生效后请用临时密码登录并立刻修改密码，勿将密码发给他人。」

## 不要做的事
- 不要把临时密码发到公共群。
- 不要跳过确认直接说已改好。
- 不要在未核实工号时重置他人账号。
