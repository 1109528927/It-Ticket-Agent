# 邮箱无法登录排查

## 现象
Outlook / 网页邮箱提示密码错误、反复要密码、或提示账号锁定。

## 排查顺序
1. 确认是否刚改过域密码：邮箱常与域同步，改密后需更新客户端保存的密码。
2. 确认账号是否被锁定：连续输错会锁，解锁或重置需走提出与确认。
3. 检查客户端：是否选错账号类型、是否开了错误的代理。
4. 网页邮箱能登而客户端不能：多半是客户端缓存密码，清凭据后重配。
5. 网页与客户端都不能登：按「忘记域密码」流程提出重置，确认后再通知。

## 与权限类的边界
仅「收信权限不够、看不到某共享邮箱」属于权限类，不要按密码问题重置。

## 记录要求
在工单回复里写清：已核对工号、是否提出重置、是否已确认、通知渠道。
