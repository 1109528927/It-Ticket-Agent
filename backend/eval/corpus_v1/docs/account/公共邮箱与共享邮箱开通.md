# 公共邮箱与共享邮箱开通

## 适用
部门公共邮箱、项目共享邮箱、会议室资源邮箱；不是个人邮箱开通。

## 申请信息
1. 显示名称、邮件地址前缀、所属部门、用途说明。
2. 主负责人与代理人；读写成员名单或权限组。
3. 是否需要外部收信、自动转发（外发转发需安全评估）。

## 处理步骤
1. 核对命名是否符合公司规范（避免与现网冲突）。
2. 创建邮箱对象后，把访问权加在权限组上，少直接挂个人。
3. 变更权限走提出与确认；开通完成后通知负责人在 Outlook 添加共享邮箱。
4. 外发大量营销信需求转邮件网关 / 市场规范流程，不在本手册随意开中继。

## 与个人邮箱区别
个人入职开通见「新员工入职账号开通清单」；本手册只覆盖共享 / 公共邮箱。
