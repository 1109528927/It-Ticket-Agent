# 业务系统角色对照说明

## 说明
本文供客服选权限组时对照，避免把「角色名」和「权限组名」混用。

## 示例对照（可按公司实际改）
| 岗位直觉 | 建议权限组名（示例） | 备注 |
|----------|----------------------|------|
| 普通员工 | emp_basic | 基础办公 |
| 部门助理 | emp_assist | 含部门共享盘 |
| 财务只读 | finance_read | 不可导出时另注明 |
| 财务经办 | finance_ops | 高风险，须主管同意 |
| 系统只读运维 | it_readonly | 不含改密与改权 |

## 助手用法
起草回复时可引用本组名称；真正变更仍只能 propose 后确认。
