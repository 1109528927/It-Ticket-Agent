# 密码策略与到期提醒

## 公司策略要点（示例，以制度正文为准）
- 最短长度、复杂度、禁止与近 N 次历史密码相同。
- 定期到期：到期前邮件 / 客户端会提示；过期后只能改密或走客服重置。
- 禁止在聊天、截图、公共网盘存放明文密码。

## 员工自助
1. 收到到期提醒后，在域改密页或 Ctrl+Alt+Del 修改。
2. 改密后同步更新 Outlook、VPN、笔记本开机保存的旧密码。
3. 改密失败提示「不符合策略」：加长、换特殊字符，不要连试导致锁定。

## 客服处理
1. 确认是否已过期或即将过期。
2. 可指导自助改密；无法登录时按「忘记域密码」提出重置并确认。
3. 反复撞策略：说明当前规则摘要，勿口头放宽策略。

## 不要做的事
- 不要为方便帮员工设成弱密码。
- 不要关闭到期策略「临时通融」而不走变更审批。
