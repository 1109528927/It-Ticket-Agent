# 单点登录（SSO）失败排查

## 现象
点「企业微信 / 钉钉 / 门户 SSO 登录」后转圈失败、跳回登录页、或提示票据无效。

## 排查顺序
1. 确认员工域账号正常、未锁定、密码未过期。
2. 清浏览器 Cookie / 换无痕窗口再试；公司门户与业务系统时钟差过大也会导致断言失败。
3. 是否刚改过密码：部分 IdP 会话未刷新，退出门户后重新 SSO。
4. 仅某一个业务系统失败：查该系统是否接入变更、回调地址是否仍有效，升级该系统管理员。
5. 全员 SSO 失败：立刻升级身份平台 / 安全组，不要逐人重置密码。

## 边界
SSO 失败不等于一定要重置域密码；先分清是会话、时钟还是 IdP。涉及改密仍须提出并确认。

## 结案
写明：已核对账号状态、浏览器侧动作、影响范围（单人 / 单系统 / 全员）。
