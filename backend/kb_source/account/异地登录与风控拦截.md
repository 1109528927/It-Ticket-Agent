# 异地登录与风控拦截

## 现象
提示「非常用地点登录」、验证码轰炸、账号被风控临时限制，或安全组来电核验。

## 客服处理
1. 核实报障人身份与工号；询问是否本人出差 / 驻场。
2. 有盗号嫌疑（用户否认登录、伴随改密邮件）：先升级安全组，不要直接解锁或重置后不管。
3. 确认为本人：按制度完成二次核验后，可指导通过 MFA 解封，或提出解锁 / 重置并确认。
4. 记录登录大致时间、地点、终端类型，便于安全溯源。

## 员工建议
- 出差前提前在门户登记差旅或开启旅行模式（若公司提供）。
- 不要把验证码告诉他人；客服不会索要完整短信验证码用于「代登录」。

## 边界
风控拦截可能同时锁账号与限制 VPN；按现象分别对照账号锁定、VPN 手册，安全事件以安全组结论为准。
