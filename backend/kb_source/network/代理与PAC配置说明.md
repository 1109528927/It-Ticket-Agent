# 代理与 PAC 配置说明

## 何时需要代理
访问指定外网资源、代码源、云控制台时，公司可能要求走统一代理或 PAC 自动脚本。

## 员工侧
1. 系统代理选择「自动检测 / 使用安装的 PAC」；不要长期手填不明代理地址。
2. 浏览器与系统代理不一致时，会出现「只有某个浏览器能上」。
3. 关代理后内网正常、开代理后异常：把报错与目标网址提交工单。

## 客服处理
1. 核对是否应使用公司 PAC URL；重装桌面代理组件。
2. 业务系统白名单未加：转网络 / 安全开白，勿让员工开「全局代理软件」翻墙式绕过。
3. 记录：操作系统、浏览器、PAC 地址、失败 URL。

## 边界
DNS 问题与代理问题常被混淆：能解析但不能连、或只有走代理才通，按本手册；纯解析失败先看 DNS 手册。
