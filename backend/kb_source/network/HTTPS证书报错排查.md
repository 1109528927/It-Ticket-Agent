# HTTPS 证书报错排查

## 现象
浏览器提示「您的连接不是私密连接」、证书过期、名称不匹配、不受信任。

## 排查
1. 系统时间是否不准（错前后很多年会导致证书校验失败）。
2. 是否公司内部站点：需安装 / 更新企业根证书；对照桌面基线。
3. 仅某个站点：把完整 URL 与截图给该系统负责人，可能是服务端证书过期。
4. 全网 HTTPS 都报错：查系统时间、根证书存储是否被误删。

## 不要做的事
- 不要习惯性点「继续访问」处理生产敏感系统而不报修。
- 不要让员工随便安装来路不明的根证书。

## 与代理
部分站点需经安全代理做 SSL 解密，证书提示可能正常；先确认是否应走代理，参见代理说明手册。
