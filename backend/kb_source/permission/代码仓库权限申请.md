# 代码仓库权限申请

## 适用
GitLab / GitHub 企业版 / 内源平台的读、写、维护者权限。

## 申请信息
1. 仓库路径或项目组、目标角色（Guest / Developer / Maintainer 等）。
2. 工号、是否外包、是否需要 CI 触发权。
3. 主管审批记录。

## 处理
1. 对照岗位与仓库密级；核心生产库写权限从严。
2. 变更在仓库平台执行或经统一权限平台；对接本系统时提出变更并确认。
3. 离职 / 调岗必须收回写权限，可与离职账号流程并行检查。

## 边界
仓库服务器都连不上：先网络 / VPN；能进平台但看不见项目：才是本手册权限问题。
