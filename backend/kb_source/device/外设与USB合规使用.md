# 外设与 USB 合规使用

## 适用范围
U 盘、移动硬盘、无线鼠标键盘、摄像头等外设接入办公电脑。

## 合规要点
1. 仅允许公司发放或登记过的存储类 USB；私人 U 盘默认只读或禁用（以终端策略为准）。
2. 写入机密资料到移动介质须符合数据外发审批。
3. 来路不明的 USB 禁止插公司电脑（防恶意设备）。

## 客服处理
1. 「插了没反应」：查设备管理器、USB 口、策略是否禁用存储类设备。
2. 需要临时放开写入：走权限 / 安全审批，设到期收回。
3. 疑似中毒或异常弹窗：断网升级安全组，保留现场。

## 与耳机麦克风
纯音视频外设优先看「耳机麦克风无法使用」；本手册侧重存储与合规外设。
